Park Opticon
============

This repository contains:

- parkopticon/   Expo / React Native mobile app
- backend/       Go API, PostgreSQL/PostGIS migrations, alert worker
- admin-portal/  React/Vite administration UI

Start with README.md for the current project overview and docs/README.md for
maintained documentation. Older setup/design milestone files are intentionally
marked as historical references and should not be used as current commands or
release guidance.
